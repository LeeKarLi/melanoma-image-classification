# melanoma-image-classification
My contribution to an ongoing group project investigating CNN-based melanoma image classification.

# Project Overview
This ongoing university group project investigates melanoma classification using convolutional neural networks and medical-image data. The project currently compares image-based classification models and will later evaluate a fusion model.
This repository documents my individual contribution to the project. The final methodology and results may change after the fusion model has been evaluated.

# My Contribution
My work currently includes:
- Exploring the image dataset and class distribution
- Investigating class imbalance
- Preparing data for training, validation and testing
- Performing image preprocessing
- Developing and evaluating three image-classification model architectures
- Comparing the performance of the three image models
- Identifying ResNet as the best-performing image-only model so far

# Current Results
Three image-classification models have been developed and evaluated. Among these models, ResNet currently provides the strongest performance based on the evaluation results obtained so far.
The specific evaluation metrics and comparison table will be added after the results have been finalised.

# Current Status
The image-model comparison has been completed. ResNet is currently the strongest image-only model.
The project is now waiting for the development and evaluation of the fusion model. The final model selection and conclusions will be determined after comparing the fusion model with the image-only models.
